# Robot Control Package

## 1. 项目简介

本项目用于控制双板四指外骨骼/手指执行系统，支持以下两种使用方式：

1. **图形界面控制（GUI）**
   - 适合手动调试、查看位置反馈、测试单指动作和热键控制

2. **终端输入流控制**
   - 适合在 VS Code 终端中直接输入动作序列
   - 例如输入 `2345 1234` 来按顺序演示不同手指动作

本项目核心控制逻辑统一封装在 `robot_core.py` 中，GUI 与终端程序共用同一套底层控制接口。

---

## 2. 文件说明

### `robot_core.py`
核心控制模块，包含：

- PID 控制器
- 板级串口连接与位置回传
- 手指映射
- `press/rest` 动作调用
- `preset` 动作调用

### `robot_gui.py`
图形界面程序。

主要功能包括：

- 两块板连接/断开
- 单指目标位置设置
- `press/rest` 动作测试
- 热键控制
- PID 参数调试
- 实时日志显示

### `robot_stdin.py`
终端输入流程序。

运行后可以在 VS Code 终端直接输入动作序列，例如：

```text
2345 1234
```

程序将按顺序执行对应手指动作。

### `motor_config.json`
定义单指动作参数：

- `press`
- `rest`

### `preset_config.json`
定义多手指联合动作参数：

- `relax`
- 其他自定义预设

### `PROTOCOL.md`
协议说明文档，包括：

- 下位机串口协议
- 终端输入协议
- 动作执行规则

## 3. 环境要求

建议使用 Python 3.10 及以上版本。

需要安装的主要依赖：

```bash
pip install pyserial
```

如需运行 GUI，通常 Python 自带 `tkinter` 即可。若本机缺少 `tkinter`，需额外安装对应系统组件。

---

## 4. 硬件默认配置

系统默认使用两块控制板：

- **板子A**：小指、无名指
- **板子B**：中指、食指

默认串口为：

- 板子A：`COM11`
- 板子B：`COM8`

如果实际串口不同，请在程序参数或代码中修改。

---

## 5. 快速开始

### 5.1 运行 GUI

```bash
python robot_gui.py
```

GUI 适合：

- 查看当前状态
- 手动测试某一根手指
- 用热键做简单演示
- 调整 PID 和目标位置

---

### 5.2 运行终端输入流程序

```bash
python robot_stdin.py
```

程序启动并连接两块板后，你可以在终端输入动作序列：

```text
2345 1234
```

表示：

- 食指 1 秒
- 中指 2 秒
- 无名指 3 秒
- 小指 4 秒

动作会按顺序执行，每一步默认执行：

1. `press`
2. 保持指定秒数
3. `rest`

整组序列执行结束后，程序会尝试执行一次 `relax`。

---

## 6. 终端输入格式

基本格式：

```text
手指序列 时长序列
```

例如：

```text
23232 23222
```

表示：

- 食指 2 秒
- 中指 3 秒
- 食指 2 秒
- 中指 2 秒
- 食指 2 秒

### 手指编号

- `2`：食指
- `3`：中指
- `4`：无名指
- `5`：小指

### 时长编号

- `0 ~ 9`
- 单位为秒

### 约束

- 两段长度必须一致
- 只允许数字 `2/3/4/5`
- 时长不超过 9 秒

---

## 7. 终端附加命令

在 `robot_stdin.py` 中，除动作序列外，还支持以下命令：

### `relax`

```text
relax
```

让所有手指回到松弛位。

### `reset`

```text
reset
```

向两块板发送编码器复位命令。

### `stop`

```text
stop
```

中断当前正在执行的序列。

### `exit`

```text
exit
```

退出程序。

## 8. 配置文件说明

### 8.1 `motor_config.json`

该文件定义单根手指的默认动作参数。

示例：

```json
{
  "index": {
    "press": { "up": 5000, "down": -5000 },
    "rest": { "up": 0, "down": 0 }
  }
}
```

含义：

- `press`：按下/演示时的位置
- `rest`：松开/恢复时的位置

---

### 8.2 `preset_config.json`

该文件定义多手指预设动作。

示例：

```json
{
  "relax": {
    "pinky":  { "up": 0, "down": 0 },
    "ring":   { "up": 0, "down": 0 },
    "middle": { "up": 0, "down": 0 },
    "index":  { "up": 0, "down": 0 }
  }
}
```

当前终端输入流程序默认会在每组动作结束后尝试执行 `relax`。

---

## 9. 使用建议

1. **调试阶段优先使用 GUI**
   - 方便查看日志和手动测试单步动作

2. **演示阶段可使用终端输入流**
   - 适合在 VS Code 终端快速输入动作序列

3. **不要同时运行 GUI 和 `robot_stdin.py`**
   - 两者都会占用相同串口
   - 同时运行会导致连接失败或冲突

4. **修改动作幅度时优先改配置文件**
   - 单指动作改 `motor_config.json`
   - 联合动作改 `preset_config.json`

## 10. 常见问题

### Q1：输入 `23231 23222` 为什么报错？

因为当前协议中，手指编号只允许：

- `2`
- `3`
- `4`
- `5`

其中 `1` 不合法。

如果你想表达“食指-中指-食指-中指-食指”，应写成：

```text
23232 23222
```

### Q2：为什么程序连接失败？

常见原因：

- 串口号不是 `COM11 / COM8`
- 串口已被其他程序占用
- GUI 和终端输入流程序同时运行

### Q3：为什么动作和预期幅度不一样？

因为动作目标值来自配置文件：

- `motor_config.json`
- `preset_config.json`

请检查相关参数是否已被修改。
